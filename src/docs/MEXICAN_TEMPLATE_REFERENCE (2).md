## 🎯 UNIQUE MEXICAN WEDDING ELEMENTS

### Cultural Specificities
1. **Padrinos System**: Multiple godparents/sponsors for different ceremony elements
2. **Civil Ceremony First**: Mexican law requires civil ceremony, religious is optional
3. **Extensive Legal Documentation**: Birth certificates, ID copies for all parties
4. **Traditional Dances**: La Vibora de la Mar, Baile del Billete
5. **Mariachi**: Traditional Mexican band (almost always included)
6. **Amenities Focus**: Flip-flops for guests, extensive bathroom amenities
7. **Late Night Food**: Menú Trasnochador (midnight snack)
8. **Religious Roles**: Many specific roles in Catholic ceremony
9. **Getting Ready Sessions**: Formal photo sessions before ceremony
10. **Happening Events**: Additional celebration moments

### Key Differences from US Weddings
- Civil ceremony is legally required and separate
- More complex paperwork requirements
- More ceremony roles and participants
- Mariachi is signature entertainment
- Late-night food is standard (not just cake)
- More elaborate guest amenities
- Separate bachelorette party planning section

### Timeline Calculation Rules
```javascript
function calculateDaysBeforeWedding(section, itemName) {
  if (section === 'Información General') return 365; // 12 months
  if (section === 'Proveedores') {
    if (itemName.includes('Lugar') || itemName.includes('salon')) return 365;
    if (itemName.includes('Fotografía') || itemName.includes('Video')) return 300;
    if (itemName.includes('Invitaciones')) return 180;
    return 270; // 9 months default for vendors
  }
  if (section === 'Civil' || section === 'Ceremonia Religiosa') return 90;
  if (section === 'Despedida de Soltera') return 45;
  if (section === 'Getting Ready') return 30;
  if (section === 'Sesión Formal') return 14;
  if (section === 'Cena') return 180;
  if (section === 'Entrada Novios / Vals' || section === 'Extras') return 7;
  return 90; // Default 3 months
}
```

### Priority Determination
```javascript
function determinePriority(itemName, section) {
  const urgentKeywords = ['Papeleria', 'Certificado', 'Acta', 'Licencia', 'Testigo'];
  const highKeywords = ['Novios', 'Fecha', 'Lugar', 'salon', 'Fotografía', 'Video', 'Musica'];
  
  if (urgentKeywords.some(kw => itemName.includes(kw))) return 'urgent';
  if (highKeywords.some(kw => itemName.includes(kw))) return 'high';
  if (section === 'Información General' || section === 'Civil') return 'high';
  
  return 'medium';
}
```

### Optional Task Detection
```javascript
function isOptional(itemName) {
  const optionalKeywords = [
    'Happening', 'Cabina', 'Video 360', 'Letras iluminadas',
    'Pirotecnia', 'Lluvia de papeles', 'Show de animación'
  ];
  
  return optionalKeywords.some(kw => itemName.includes(kw));
}
```
